# 🚀 Premium Focus & Task Manager

A high-performance, aesthetically pleasing To-Do List application integrated with a **Pomodoro Timer**. Designed with a modern "Clean UI" aesthetic and a vibrant gradient background.

## ✨ Key Features
* **Pomodoro Timer:** Built-in 25-minute focus timer to boost productivity.
* **Smart Progress Tracker:** Visual progress bar that updates in real-time as you complete tasks.
* **Advanced Filtering:** Sort through your tasks by *All*, *Active*, or *Completed* status.
* **Quick Search:** Instantly find tasks using the integrated search bar.
* **Priority & Categories:** Assign priorities (Low, Medium, High) and categories (Work, Personal, Study) to stay organized.
* **Persistent Storage:** Uses `localStorage` so your tasks remain even after refreshing the page.

## ⌨️ Keyboard Shortcuts
| Shortcut | Action |
| :--- | :--- |
| `Ctrl + N` | Focus on the 'New Task' input |
| `Ctrl + F` | Focus on the 'Search' bar |
| `Spacebar` | Start/Pause the Pomodoro Timer |

## 🛠️ Technology Stack
* **HTML5:** Semantic structure.
* **CSS3:** Custom properties (variables), Flexbox, and vibrant gradients.
* **JavaScript (ES6):** Dynamic DOM manipulation and LocalStorage logic.

## 🚀 How to Use
1. Clone this repository to your local machine.
2. Open `index.html` in any modern web browser.
3. Start adding tasks and crushing your goals!
